# مدیریت مالی خانواده

اپلیکیشن اندرویدی فارسی و راست‌چین برای مدیریت دخل‌وخرج خانوادگی، حساب‌های اعضا، انتقال وجه و اهداف پس‌انداز.

## امکانات فعلی
- داشبورد موجودی کل، درآمد و هزینه ماهانه
- ثبت، ویرایش و حذف درآمد و هزینه
- قالب‌بندی خودکار مبالغ با جداکننده هزارگان و پشتیبانی از ارقام فارسی و عربی
- حساب‌های مستقل برای اعضای خانواده
- انتقال وجه بین حساب‌ها با کنترل موجودی و ثبت دوطرفه
- جلوگیری از ویرایش یا حذف جداگانه سطرهای انتقال برای حفظ تراز حساب‌ها
- جست‌وجو و فیلتر تراکنش‌ها بر اساس درآمد و هزینه
- گزارش ماهانه و هزینه به تفکیک دسته
- بودجه ماهانه با نمایش میزان مصرف و امکان حذف بودجه
- نمایش مبلغ باقی‌مانده بودجه، درصد مصرف و هشدار برجسته هنگام عبور از سقف هزینه
- اهداف پس‌انداز با ثبت واریزی و امکان حذف هدف
- تاریخ شمسی
- پوسته روشن و تاریک با ذخیره انتخاب کاربر
- تهیه و بازیابی پشتیبان SQLite با بررسی سلامت فایل و بازگردانی نسخه قبلی در صورت خطا
- رابط گرافیکی تیره با کارت‌های نیمه‌شفاف، گرادیان و نماد اختصاصی برنامه

## فناوری
- Kotlin
- Android Jetpack Compose و Material 3
- SQLite محلی از طریق SQLiteOpenHelper
- GitHub Actions برای آزمون و ساخت APK

## ساخت و دریافت APK
با هر Push به شاخه `main` یا اجرای دستی گردش‌کار **Android verification and release**، آزمون‌های واحد و ساخت APK اجرا می‌شوند.

- فایل Debug پس از موفقیت آزمون‌ها به‌صورت Artifact با نام `family-finance-v0.7.0-debug-apk` در دسترس است.
- در صورت تنظیم هر چهار Secret امضای اندروید، گردش‌کار علاوه بر Debug، نسخه Release امضاشده را نیز می‌سازد، امضای آن را بررسی می‌کند و Artifact با نام `family-finance-v0.7.0-release-apk` منتشر می‌کند.
- چهار Secret موردنیاز عبارت‌اند از `ANDROID_KEYSTORE_BASE64`، `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS` و `ANDROID_KEY_PASSWORD`.
- فایل keystore و رمزهای آن نباید در مخزن کد یا در پیام‌های عمومی قرار بگیرند. از فایل keystore نسخه پشتیبان امن و آفلاین نگهداری کنید.

برای دریافت فایل‌ها، در مخزن به بخش **Actions** بروید، اجرای موفق را باز کنید و Artifact موردنظر را از قسمت **Artifacts** دانلود کنید.
