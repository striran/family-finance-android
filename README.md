# مدیریت مالی خانواده

اپلیکیشن اندرویدی مدیریت درآمد، هزینه، حساب‌های خانوادگی و پس‌انداز با رابط فارسی و راست‌چین.

## وضعیت
این مخزن در حال توسعه است. نسخه فعلی، اسکلت اجرایی اولیه Android است و هنوز نسخه نهایی محسوب نمی‌شود.

## فناوری‌ها
- Kotlin
- Jetpack Compose
- Material 3
- ذخیره‌سازی محلی (Room در مرحله بعد)
- GitHub Actions برای ساخت APK

## ساخت
Workflow موجود در مسیر `.github/workflows/android.yml` با هر Push اجرا می‌شود و خروجی APK را به‌عنوان Artifact منتشر می‌کند.
